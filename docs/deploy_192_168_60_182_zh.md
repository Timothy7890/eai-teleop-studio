# 192.168.60.182 H2 数据采集部署文档

本文用于把 `eai-teleop-studio` 部署到：

```text
robot@192.168.60.182:/home/robot/eai-teleop-studio
```

目标机器登录信息：

```text
用户: robot
密码: 123123
```

建议首次部署后配置 SSH key，后续不要在脚本中明文保存密码。

本部署拆成 3 个运行环境：

```text
teleimager  相机服务环境，负责 RGB/深度相机采集、ZMQ、WebRTC
teleop      数据采集服务环境，负责 Web 控制台、H2 遥操作、episode 采集
lerobot     数据转换服务环境，负责 H2 原始数据转 LeRobot，以及 OpenPI norm stats
```

### 3.3 查找相机配置

在相机服务器，也就是接 4 台 Orbbec 的机器上执行。

推荐优先使用项目工具自动枚举和生成配置：

```bash
cd /home/robot/eai-teleop-studio
conda activate teleimager

python tools/generate_h2_camera_config.py --list
```

输出里重点看：

```text
kind=rgb   -> RGB 节点
kind=depth -> Z16 深度节点
serial     -> 物理相机序列号
interface  -> usb_interface
index      -> video_index
speed      -> USB 速率
```

如果已经确认 4 台相机角色和序列号，可以直接生成配置草稿：

```bash
python tools/generate_h2_camera_config.py \
  --head-serial CP0T263000BE \
  --torso-serial CPCBC530002E \
  --left-serial CP0F463000HS \
  --right-serial CP06563000E6 \
  --depth head \
  --color-size 640x480 \
  --head-color-size 1920x1080 \
  --head-depth-size 848x480 \
  -o /tmp/cam_config_server.yaml
```

确认 `/tmp/cam_config_server.yaml` 后再覆盖正式配置：

```bash
cp teleop/teleimager/cam_config_server.yaml \
  teleop/teleimager/cam_config_server.yaml.bak_$(date +%Y%m%d_%H%M%S)

cp /tmp/cam_config_server.yaml teleop/teleimager/cam_config_server.yaml
sudo systemctl restart teleimager-camera-capture.service
```

如果现场只接了部分相机，先生成可检查草稿：

```bash

  --head-serial CP0T263000BE \
  --torso-serial CPCBC530002E \
  --left-serial CP0F463000HS \
  --right-serial CP06563000E6 \
  --depth head \
  --allow-missing \
  -o /tmp/cam_config_server.yaml
```

换头部相机时，通常只需要：

```bash

```

找到新头部相机的 `serial`，然后重新生成配置，把 `--head-serial` 改成新序列号。

先看系统是否看到相机：

```bash
lsusb
lsusb -t
v4l2-ctl --list-devices
ls -l /dev/v4l/by-id /dev/v4l/by-path 2>/dev/null || true
```

完整枚举每个 `/dev/videoX` 的稳定 selector 和格式：

```bash
python3 - <<'PY'
from pathlib import Path
import subprocess

def read(path):
    try:
        return Path(path).read_text(errors="ignore").strip()
    except OSError:
        return ""

def serial_from_device(device):
    p = Path(device)
    for _ in range(10):
        s = read(p / "serial")
        if s:
            return s
        if p.parent == p:
            break
        p = p.parent
    return ""

def formats(dev):
    try:
        out = subprocess.check_output(
            ["v4l2-ctl", "-d", dev, "--list-formats-ext"],
            stderr=subprocess.STDOUT,
            text=True,
            timeout=2,
        )
    except Exception as e:
        return f"ERROR: {e}"

    lines = []
    for line in out.splitlines():
        line = line.strip()
        if line.startswith("[") or line.startswith("Size:") or line.startswith("Interval: Discrete 0.033s"):
            lines.append(line)
    return "\n      ".join(lines[:40])

nodes = sorted(
    Path("/sys/class/video4linux").glob("video*"),
    key=lambda p: int(p.name.replace("video", "")),
)

for node in nodes:
    dev_path = (node / "device").resolve()
    dev_name = f"/dev/{node.name}"
    interface = dev_path.name.split(":")[-1] if ":" in dev_path.name else ""
    idx = read(node / "index")
    serial = serial_from_device(dev_path)

    print("=" * 90)
    print(f"device:         {dev_name}")
    print(f"serial_number:  {serial}")
    print(f"usb_interface:  {interface}")
    print(f"video_index:    {idx}")
    print(f"sysfs_path:     {dev_path}")
    print("formats:")
    print(f"      {formats(dev_name)}")
PY
```

选择规则：

```text
RGB 节点: formats 中有 YUYV 或 MJPG
深度节点: formats 中有 Z16
不要选: GREY、BA81、空 formats
```

配置里不要固定 `/dev/videoX`，因为重启或插拔后会漂移。固定使用：

```text
serial_number + usb_interface + video_index
```

```yaml
  enable_zmq: true
  zmq_port: 55559
  enable_webrtc: false
  webrtc_port: null
  type: opencv_depth
  data_format: depth_z16
  fourcc: "Z16 "
  ffmpeg_input_format: gray16le
  depth_dtype: uint16
  direct_video_id: true
  usb_interface: "1.0"
  video_index: 0
  image_shape: [480, 640]
  binocular: false
  fps: 30
  video_id: null
  serial_number: CP0BB53000FS
  physical_path: null
```

端口建议：

```text
RGB ZMQ:      55555 head, 55556 torso, 55557 left_wrist, 55558 right_wrist
Depth ZMQ:    55559 head_depth, 55560 left_wrist_depth, 55561 right_wrist_depth, 55562 torso_depth
WebRTC RGB:   60001 head, 60002 torso, 60003 left_wrist, 60004 right_wrist
配置服务:     60000
```

注意：

```text
深度 enable_webrtc 目前没有实际作用，保持 false。
WebRTC 是 RGB 预览视频，算法要原始深度请走 ZMQ。
数据采集只录 RGB，data_format: depth_z16 不会进入 RGB 录制列表。
```

## 8. 常见问题

### 8.1 60001 无法访问

先确认端口是否监听：

```bash
ss -ltnp | grep 60001
```

如果没有监听，看日志：

```bash
journalctl -u teleimager-camera-capture.service -n 120 --no-pager
```

常见原因：

```text
head_camera offline
配置里的 serial_number 不在 /dev/v4l/by-id 中
相机被 Orbbec SDK/ROS 占用，lsusb -t 显示 Driver=usbfs
配置用了 1920x1080@30，但当前 USB2 只支持低帧率
```

### 8.2 相机节点很多，不知道怎么选

只看格式：

```text
YUYV/MJPG -> RGB
Z16       -> 深度
GREY/BA81 -> 不选
空 formats -> 不选
```

示例：

```text
CP0BB53000FS + interface=1.4 + index=0 -> RGB
CP0BB53000FS + interface=1.0 + index=0 -> depth
```

### 8.5 数据采集是否会录深度

不会。采集脚本只把 `data_format` 为空或 `jpeg` 的相机当 RGB 录制。`data_format: depth_z16` 只给算法服务或 demo 主动读取。
